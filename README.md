# LifeTracker Frontend

LifeTracker 个人时间审计与习惯管理系统 - 现代前端工程。

## 技术栈
- React 18 + Vite 5
- Ant Design 5.x（深色系极客主题设计）
- Three.js（3D 粒子自律能量场与视差动态交互）
- ECharts 5.x（极坐标玫瑰图、5维雷达图）
- Canvas Confetti（打卡庆祝微交互）

## 快速启动
```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev
```
前端服务默认监听: `http://localhost:5173`
